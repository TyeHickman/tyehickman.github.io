This site is an exercise in information architecture as much as web development. The central design problem is presenting several connected practices—software engineering, game development, hobby robotics, and creative writing—without splitting them into separate identities.

The implementation stays deliberately small: Jekyll, semantic HTML, and a two-layer stylesheet boundary. A reusable Grimmoire web artifact provides the visual language; site-owned CSS handles navigation, collections, and composition.
